# Тёмные знания — квиз-битва против Босса

Простая карточная веб-игра для компании (**8–12 игроков**, режимы **Классика**, **Быстрый и мёртвый** и **Война гильдий**) в стиле **dark fantasy**.
Всё в одном файле `index.html` — работает **офлайн**, без интернета и установки.
Открывается двойным кликом в любом браузере (Microsoft Edge / Chrome) на Windows 10 и Windows 11.

**Версия 1.0.4.** Добавлен **режим разработчика** и **таблица лидеров**. Во время боя (битвы с Боссом и Мордобоя) сочетание **Ctrl + M** включает и выключает режим разработчика: в правом нижнем углу появляется кнопка 🛠️, которая открывает меню с уроном/лечением по конкретному игроку и по Боссу (количество вводится с клавиатуры), а также отменой действий — **«на ход назад»** (последний ответ отменяется, у отвечавшего будет новый вопрос) и **«в начало круга»** (все ходы круга отменены, HP возвращаются к значениям начала круга, вопросы всем новые, отменённые казино, супервопрос и проклятие смогут выпасть снова). В меню **«⋯»** появился пункт **«🏆 Таблица лидеров»** — только игроки и сумма их баллов **за всё время и за все игры**; таблицу можно **экспортировать и импортировать в JSON**, импорт **сливает** сохранения: игроки из разных файлов собираются в одну таблицу.

**Версия 1.0.3.** В игру перенесён **весь проверенный банк**: вместо отобранных 100 вопросов теперь **741 вопрос** — История и мифы (150), Наука (150), Искусство и музыка (146), Поп-культура (148), Компьютерные игры (147). ## Управление с клавиатуры

- **1 / A, 2 / B, 3 / C, 4 / D** — вариант ответа после «Показать ответы» (в русской раскладке — **А, Б, В, Г**); при выборе сложности — **1, 2, 3** (★, ★★, ★★★).
- **Пробел** — «Показать ответы», затем — «Следующий ход».
- **O** (английская) — открыть **Настройки**; **Esc** — закрыть любое открытое окно (**Настройки**, **Правила**, **Оформление**, **Таблица лидеров**, **Режим разработчика**).
- **Ctrl + M** — включить/выключить **режим разработчика** (только пока идёт бой; подробности ниже).
- **Esc** на экране выбора игроков или команд — возврат в главное меню.
- Финальная анимация (конфетти при победе, огонь при поражении) проигрывается **один раз** и не запускается повторно ни клавишей пробела, ни кнопками.

## Как запустить

1. Скопируйте файл `index.html` на флешку (или скачайте ZIP репозитория).
2. На нужном компьютере откройте файл **`index.html` двойным кликом**.
3. Для красоты на презентации нажмите **F11** — полноэкранный режим.

## Правила игры

При запуске первым открывается **меню выбора режима** (при наведении на кнопку появляется краткое описание):

- **Классика** (одиночная) — каждый сам за себя: 8–12 игроков.
- **Быстрый и мёртвый** (быстрая) — короткий бой без сюрпризов: 8–12 игроков, у каждого 250 HP, у Босса 750 HP.
- **Война гильдий** (командная) — 4–6 гильдий по 2 игрока.

### Классика (одиночная игра)

- На старте выбирается **число игроков от 8 до 12** и заполняются никнеймы. Запас HP зависит от числа: **8–9 → 500**, **10 → 400**, **11–12 → 300**. У каждого игрока своя аватарка.
- Можно задать **имя Босса** — или оставить поле пустым, тогда он сам назовёт себя: *Владыка тьмы*, *Повелитель ужаса* или *Лорд теней*.
- Ход выбирается **рандомно**, но за круг отвечают **все** игроки (очередь перемешивается каждый круг).
- На своём ходу игрок выбирает карту темы со стола (5 тем), а затем — **сложность вопроса: ★, ★★ или ★★★** (на карточке — одни звёзды). **Одну и ту же сложность нельзя выбирать дважды подряд одному игроку** — заблокированная кнопка гаснет.
- Дано **15 секунд** на ответ — варианты скрыты, пока ведущий не нажмёт «Показать ответы»; таймер стартует в этот момент. У мегавопроса таймера нет.
- **Правильный ответ** → урон Боссу: ★ = 50, ★★ = 100, ★★★ = 150. **Неправильный ответ** → урон самому игроку: ★ = **100**, ★★ = **125**, ★★★ = **150** (риск виден на карточке). Варианты ответов показываются в случайном порядке.
- ⚡ **Серия:** у игрока 5 верных ответов **подряд** — с шансом **5%** босс вместе с пятым ударом получает ещё **+300 HP** («СЕРИЯ 5 ПОДРЯД!»). Серию засчитывают **только обычные вопросы** — мега и проклятие не увеличивают серию и не сбрасывают её; любой **неправильный** ответ сбрасывает.
- 👹 **Ярость Босса:** с независимым шансом **5% за каждый неправильный ответ** Босс **удваивает урон** об ошибившемся игроке (звучит рёв, всплывает «БОСС РАЗЪЯРЁН»).
- 🛡 **Спокойное начало:** особые события не сыплются в самом начале — первые **3 вопроса** игры проходят **без мегавопроса, проклятия и казино**; после этого шанс каждого события плавно нарастает (от половины базового до полного) и дальше остаётся прежним.
- 🔥 **Мегавопрос** — один раз за игру: он сносит **400 HP** (боссу при верном ответе, игроку при неверном).
- ☠ **Вопрос-проклятие** — редкий вопрос: неверный ответ — **−100 HP всем игрокам**, верный — жертва (Босс или цель) восстанавливает **+100 HP**.
- 🔒 **Нельзя брать одну и ту же тему дважды подряд** (у каждого игрока своя память выбора): при наведении на уже взятую карточку она загорается красным, клик не срабатывает. Исключение — если незаполнена осталась только одна колода.
- 🎴 **Три способности у каждого игрока** (появляются зелёными кнопками в углу окна с вопросом, каждая — **один раз за игру**):
  - **🔀 Замена** — поменять этот вопрос на другой (та же сложность, если есть);
  - **⚡ Азарт** — урон этого вопроса **×2**, но при ошибке сам получаешь ровно **200**;
  - **🎴 Передача** — отдать вопрос случайному живому сопернику и **пропустить свой ход** (только в битве с боссом).
  - Способности действуют **только на обычном вопросе и только до нажатия «Показать ответы»**: в мегавопросе, вопросе-проклятии и казино они отключены (после показа ответов кнопки гаснут).
- 🎰 **Казино** — **один раз за игру**, только в битве с боссом: вместо вопроса игрок жмёт **«Крутить»** и барабан долго вращается, плавно останавливаясь. Выпадает: исцеление **+50 HP**, **пропуск хода** рандомного игрока, урон **−100 HP**, урон Боссу **−100 HP**, урон случайному сопернику **−50 HP** или ничего.
- У игрока 0 HP — он **выбывает**.
- 🔥 **Конец II круга:** если босс ещё цел, он обрушивает удар по **всем живым** — каждый игрок теряет **−50 HP**, пул каждой команды — **−100 HP** (баннер «КОНЕЦ II КРУГА»).
- 🌕 **Кровавая луна** (начало II круга; только в Классике и Войне гильдий): с шансом **50%** — может не выпасть за игру вовсе. Пока она длится, **весь урон ×1.2** — и босса, и игроков (**кроме мега, проклятия и казино**); экран плавно наливается кровью (**отдельной луны на фоне нет — только красный оттенок**), **луна темы краснеет**, на Хеллоуин **огонь в тыквах становится красным**; появление и исчезновение — плавные анимации. С началом III круга всё возвращается в норму.
- 👑 **Конец III круга:** если босс ещё цел, он проводит **зачистку** — забирает **2–4 самых слабых** игроков (по числу участников; при уже погибших — 1–2 самых низких по HP и урону; в командном режиме — одну команду).
- Кто **добил Босса** — получает **+1 балл**. Начинается финальная фаза «Мордобой».
- **Мордобой** — дуэли в два шага: **атакующий** (красная рамка) и **защищающийся** (зелёная рамка того же размера). Вопрос задаётся обоим:
  - атакующий отвечает **первым**;
  - если он **верно** — защитнику задаётся **новый вопрос**: тот ответил верно → получает всего **50** урона, неверно → **полноценный урон** по вопросу;
  - если атакующий **промахнулся** — урон ему пока не наносится, вопрос переходит защитнику: защитник **верен** → атакующий получает **урон + 50**, **промахнулся** → **оба** получают урон по вопросу.
- Финал — когда остаётся **3 игрока**: места по нанесённому урону, призы **5 / 3 / 2 балла**.
- Если **вопросы закончились** раньше — игра завершается досрочно, места по **нанесённому урону и запасу HP**.
- ☠ **Поражение:** если босс уничтожил **всех** — на итогах красное **«💀 ПОРАЖЕНИЕ 💀»**, мишура начинает падать, но **резно сгорает в огне** (со звуком пламени), и **баллы не получает никто**.
- В итоговой таблице указано, **как погиб каждый игрок**: от Босса, от другого игрока, от своей ошибки, от проклятия или от казино.

### Быстрый и мёртвый (быстрая игра)

- Та же одиночная механика, но **без сюрпризов** — для коротких партий и демонстрации.
- У каждого игрока **ровно 250 HP** (независимо от числа участников), у Босса — **750 HP**.
- **Нет** способностей, казино, мегавопросов и вопросов-проклятий — только обычные вопросы.
- Босс **не бьёт по всех в конце II круга** и **не устраивает зачистку в конце III круга**.
- Ярость Босса и правило повтора темы/сложности работают как обычно; **бонус серии** («+300 за 5 подряд») в быстрой игре отключён; Мордобой — **обычный** (урон 100 / 150 / 200, дуэли в два шага, до последних трёх).

### Война гильдий (командная игра)

- На старте выбирается **число команд от 4 до 6** (каждая команда — 2 игрока, всего 8–12 участников): имя команды + два никнейма. Имя Босса — тоже можно задать.
- Команда сражается **как единая единица**: оба игрока делят **общий пул HP = 2 × норма** (4 команды → 1000, 5 → 800, 6 → 600).
- **Весь урон вдвое выше** — и наносимый, и получаемый: боссу ★ = 100/200/300, себе за ошибку 200/250/300, в Мордобое 200/300/400. **Исключение — мегавопрос:** он по-прежнему сносит ровно **400 HP**. Ярость Босса (5%) удваивает и так удвоенный урон.
- За команду отвечает **по очереди один из двух игроков** (ход раз за круг на команду).
- На ответ — **20 секунд** (вместо 15), а вопросы **чуть сложнее**: звёздочные ★-вопросы нередко заменяются на более сложную карту из той же колоды (сложность всё равно выбирается самим игроком).
- Запрет повтора темы и запрет повтора сложности действует **на уровне команды** (память — у отвечающего игрока); проклятие бьёт по **−100 HP в пул каждой команды**; команда при 0 HP выбывает **целиком** (оба игрока). Способности и серии — **личные**, у каждого игрока свои.
- **Мордобой** устроен так же, как в одиночной игре, но вопрос получают **обе команды**: сначала отвечает атакующий, затем защитник; урон по вопросу действует на **пул команды**.
- В итогах **баллы начисляются команде** (призы 5 / 3 / 2 и +1 за добивание Босса), места определяются суммарным уроном команды. Помимо командной таблицы выводится **отдельная статистика по каждому игроку** — команда, статус, урон, верные ответы.

### Цвета ников

Ник каждого игрока получает **случайный металлический цвет** (рубин, лазурь, изумруд, аметист…) — шрифт, стиль и блик остаются общими.

## Меню «⋯», настройки и оформление

В **правом верхнем углу главного меню** — значок **⋯** (три точки). По клику открывается меню из четырёх пунктов:

1. **⚙️ Настройки** — общие переключатели: звук (Вкл / Выкл) и **размытие фона** (фон и сцены размываются на 15%, интерфейс остаётся резким): действуют во всей игре и запоминаются. Чтобы размытие не тормозило игру, пока оно включено, анимации за ним автоматически **замораживаются** — размазанный фон статичен, браузер кэширует его и не пересчитывает каждый кадр (работает плавно даже на слабом компьютере).
2. **📜 Правила** — подробное, но простое изложение правил: акт Битвы с Боссом, особые события, Мордобой, режимы и способности.
3. **🎨 Поменять оформление** — шесть тем, выбор применяется сразу и **запоминается**:
   - 🗡 **Дарк Фэнтези** — чёрно-фиолетовый туман, золото и рубин (базовая); на фоне — **очень тёмная гора**, а на склоне стоит **холм с готическим замком, стоящим на самом холме** (замок и гора почти чёрные), над замком светит **красная кровавая луна**, а в небе **мерцают кровавые звёзды**;
   - 🎃 **Хеллоуин** — фиолетово-оранжевые сумерки; по небу **пролетают чёрные силуэты летучих мышей**, внизу стоят **большие тыквы, внутри которых мерцает огонь**, а **между тыквами — два огромных (почти втрое выше прежних) чёрных засохших дерева со сломанными макушками и ветвями-когтями; на правом — два страшных глаза и ровная улыбка строго по центру ствола, они светятся и пульсируют красным**;
   - 🎄 **Новый год** — глубокая новогодняя **ночь**: **луна посередине неба** и мерцающие звёзды, по небу летит упряжка — **сначала олени, соединённые между собой верёвками упряжи**, за ними сани с **Сантой-силуэтом, который смотрит вперёд (вправо, за оленями) — чёрный, как тень, борода и нос читаются по профилю**; внизу — **сугробы снега**, **большая ёлка с мигающей гирляндой и стволом** и **снеговик в цилиндре слева**, поверх сценки **непрерывно идёт снег**;
   - 🌸 **Япония** — тёмное вино и сакура: слева на фоне **большое цветущее дерево сакуры**, а справа — **большая цветущая ветка сакуры**, идущая **от центра правого края экрана вверх к самому верху**; с них непрерывно сыплются розовые **лепестки**;
   - 🌟 **Звёздное небо** — глубокая ночная синева с туманностями и **мерцающими звёздами** по всему экрану, а в центре — **очертания Млечного пути**: светящаяся полоса с двумя кромками, тёмной пыльной дорожкой и россыпью звёзд; **изредка пролетают падающие звёзды** — яркая искра со светящимся следом летит по небу 1–2 секунды и гаснет, а **очень редко по самому низу экрана проплывает маленькая космическая ракета** (4–5 секунд, с мерцающим пламенем);
   - 📓 **Тетрадь** — весь фон становится **листом тетради в линейку** с красным полем, текст выглядит **написанным карандашом**, а рамки панелей и карточек сделаны из **картона**; **ники игроков написаны цветными карандашами** — у каждого свой цвет (карточки, дуэли, подписи хода, подиум и таблица итогов), а в **правом верхнем углу листа — чёрная чернильная клякса** с каплями и брызгами.
4. **🏆 Таблица лидеров** — накопительная таблица результатов: **только игроки и сумма их баллов за всё время, за все игры**. Места пронумерованы (топ-3 — медалями), список отсортирован по убыванию баллов. Есть **экспорт и импорт в JSON** (кнопки внутри окна): экспорт скачивает файл `temnye-znaniya-leaderboard.json`, а импорт **объединяет** сохранения — если скрестить два файла с разными игроками, все они окажутся в одной таблице, а баллы одинаковых игроков **сложатся**. Баллы за игру записываются автоматически на итогах (в командном режиме баллы команды записываются каждому её участнику); данные хранятся в браузере и не теряются между партиями.

Тема меняет палитру интерфейса (панели, рамки, акценты, металл заголовков), фон и оформление фона. **Полупрозрачный узор-эмодзи по фону убран на всех темах** — остаются только чистый фон, сцены и звёзды. Звуки и механика не зависят от темы.

**Крупный бой.** На экранах боя — Битвы с Боссом и Мордобоя — **весь интерфейс увеличен на 19%**: плашки, карточки игроков, карточка вопроса с таймером и способностями, баннеры кругов, колесо фортуны и весь текст (масштаб включается автоматически на время боя и выключается в итогах). Ширина и высота карточек при этом подгоняются под масштаб по vw/vh, чтобы ничего не вылезало за экран — читать удобно с любого места аудитории.

**Аватарки** тоже зависят от оформления: базовый набор (вампир, волк, зомби, колдун, бес, тролль…) дополняется **шестью тематическими** аватарками — ведьмы и огры на Хеллоуин, Дед Мороз и олени на Новый год, ниндзя и кицуне в Японии, пришельцы и планеты в Звёздном небе, карандаши и скрепки в Тетради.

## Режим разработчика (для ведущего)

Сочетание клавиш **Ctrl + M** во время боя (**битва с Боссом** или **Мордобой**) включает режим разработчика; повторное нажатие выключает его. Вне боя клавиша ничего не делает.

- При включении в **правом нижнем углу** появляется кнопка **🛠️** — она открывает панель разработчика (Esc или «✕ Закрыть» закрывает панель, кнопка остаётся).
- **① Урон или лечение игрока** — выпадающий список целей (в командном режиме — команды) и поле, куда **с клавиатуры вводится количество**; кнопки «⚔ Нанести урон» и «💚 Вылечить». Вылеченного выбывшего игрока панель **возвращает в бой**.
- **② Урон или лечение Босса** — то же самое для Босса (секция видна только в фазе битвы).
- **③ Отмена действий**:
  - **↩ Вернуться на ход назад** — отменяет последнее действие: урон и статистика последнего ответа снимаются, а у отвечавшего **будет новый вопрос** (прежний убирается из колоды, чтобы не повторился);
  - **⟲ В начало круга** — отменяет **все ходы круга**: HP всех игроков и Босса возвращаются к значениям **начала круга**, счётчики событий откатываются (уже выпавшие **казино, супервопрос и проклятие смогут появиться снова**), а вопросы круга уходят из колоды — всем достанутся **новые**.
- Панель показывает номер круга, фазу и число сохранённых снимков; отмена работает только пока идёт бой и не в момент переходных анимаций.

## Структура игры (для настройки)

Всё лежит в `index.html` внутри тега `<script>`:

| Имена Босса | `BOSS_NAMES` (если поле ввода пустое) |
| Ярость Босса (удвоение урона) | `BOSS_DOUBLE_CHANCE` (0.05) |
| Урон боссу ★/★★/★★★ | `DMG` (50/100/150) |
| Урон себе за ошибку против босса | `DMG_SELF` (100/125/150) |
| Урон в Мордобое ★/★★/★★★ | `DMG_PVP` (100/150/200) |
| Урон и шанс мегавопроса | `MEGA_DMG` (400), `MEGA_CHANCE` (0.12) |

| Казино | `CASINO_CHANCE` (0.07), `CASINO_SPIN_MS` (6500), сектора `CASINO` |

Формат вопроса:

```js
{difficulty: 2,                       // 1 = ★, 2 = ★★, 3 = ★★★

```

Текущие 741 вопрос (v1.0.3) — **проверенный вручную** банк из пяти тем; их можно полностью заменить на свои, сохранив формат.

## Технологии

- Чистые HTML + CSS + JavaScript, без библиотек и внешних ресурсов.
- Шрифт **Tagesschrift (кириллица)** встроен прямо в файл (base64) — работает офлайн.
- Заголовки и имена оформлены **металлом**: хромовой градиент + бегущий блик, оттенок каждого цвета сохранён; у каждого игрока — свой цвет ника.
- Название на первом экране — **«Тёмные знания»**: при наведении подсвечивается фиолетовым, чуть увеличивается и мягко всплывает вверх.
- Звуки генерируются через WebAudio (кнопка 🔇 выключает), у событий свои эффекты: обнажение оружия в начале, шелест карты при наведении на тему, гонг мегавопроса, звон монет казино, рёв при удвоении урона, потрескивание пламени при сгорании мишуры на поражении, разные звуки гибели (от Босса / от игрока / за свою ошибку / от проклятия / от казино), грохот и анимация распада Босса, барабаны второго акта с анимацией выхода дуэли, финальные аплодисменты с конфетти-хлопушками.
- Наведение на карточку Босса подсвечивает её рамку красным; рамка и имена — в золотых орнаментах (.ornate).
- Работает в Microsoft Edge, Chrome, Firefox — локально с диска.
