# 🃏 Карты Битвы — квиз-битва против Босса

Простая карточная веб-игра для компании (до 10 игроков). Всё в одном файле `index.html` —
работает **офлайн**, без интернета и установки чего-либо. Открывается двойным кликом в любом
браузере (Microsoft Edge / Chrome) на Windows 10 и Windows 11.

## Как запустить

1. Скопируйте папку с игрой на флешку (или скачайте ZIP репозитория).
2. На нужном компьютере откройте файл **`index.html` двойным кликом** (откроется в браузере).
3. Для красоты на презентации нажмите **F11** — полноэкранный режим.

> Альтернатива: если у компьютера есть интернет — можно открыть игру по ссылке GitHub Pages
> (Settings → Pages → включить из ветки `main`), тогда файл копировать не нужно.

## Правила игры

- 10 игроков, у каждого **1000 HP**. У Босса тоже **1000 HP**.
- Ход выбирается **рандомно**, но за круг отвечают **все** игроки (очередь перемешивается каждый круг).
- На своём ходу игрок выбирает рубашку карты — **тему вопроса** (5 тем).
- **Правильный ответ** → урон Боссу: ★ = 50, ★★ = 100, ★★★ = 150.
- **Неправильный ответ** → столько же урона получает сам игрок.
- У игрока 0 HP — он **выбывает**.
- Кто **добил Босса** — получает **+3 балла**. Начинается **Глава II**.
- **Глава II:** игроки бьют друг друга по тому же принципу (атакующий и цель — рандомно, но все сходят по кругу). Неверный ответ — урон самому атакующему.
- Финал наступает, когда остаётся **3 игрока**. Они распределяются по местам по нанесённому урону: **5 / 3 / 1 балл**.
- В конце — подведение итогов с полной статистикой: очки, урон боссу, урон игрокам, полученный урон, верные ответы.

Ответы игроков произносятся вслух, **правильность отмечает ведущий** — он кликает по варианту,
который назвал игрок.

## Структура игры (для настройки)

Всё лежит в `index.html` внутри тега `<script>`:

| Что менять | Где |
|---|---|
| HP игроков / босса | константы `START_HP`, `BOSS_HP` |
| Урон по сложности ★/★★/★★★ | константа `DMG` |
| Баллы за добивание босса | `BOSS_KILL_BONUS` |
| Баллы за 1/2/3 место | `PRIZE` |
| **Темы и вопросы** | массив `TOPICS` — 5 тем × 10 вопросов |

Формат вопроса:

```js
{difficulty: 2,                       // 1 = ★, 2 = ★★, 3 = ★★★
 text: "Текст вопроса?",
 options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
 answer: 0}                           // индекс правильного варианта (с нуля)
```

Текущие 50 вопросов — **тестовые**, их можно полностью заменить на свои, сохранив формат.

## Технологии

- Чистые HTML + CSS + JavaScript, без библиотек и внешних ресурсов.
- Звуки генерируются через WebAudio (кнопка 🔇 выключает).
- Работает в Microsoft Edge, Chrome, Firefox — локально с диска.
