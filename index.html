📜 Правила

🎲 Суть игры

Игра идёт в три акта: Битва с Боссом → Мордобой → Итоги. Игроки отвечают на вопросы по очереди. Ведущий (или сам ноутбук) ведёт игру: показывает вопрос, варианты ответов скрыты, пока ведущий не нажмёт «Показать ответы» — тогда идёт таймер.

⚔️ Акт I. Битва с Боссом

  1. Очередной игрок выбирает тему из пяти карточек на столе (одну и ту же тему дважды подряд брать нельзя).
  2. Потом — сложность: ★, ★★ или ★★★. На кнопке сразу видно: сколько БОСС потеряет при верном ответе и сколько получит игрок при неверном. Одну и ту же сложность дважды подряд брать нельзя.
  3. Вопрос появляется на экране. Игрок думает вслух, затем ведущий жмёт «Показать ответы» — с этого момента идёт таймер (15 секунд; в командной игре 20).
  4. Верно → Босс теряет урон: 50 / 100 / 150 (по сложности). Неверно → игрок сам теряет: 100 / 125 / 150.
  5. Кто добил Босса — получает +1 балл. Все выжившие переходят к Мордобою.

👹 Особые события (обычный и командный режимы)

  • 🔥 Мегавопрос (один раз за игру): вместо обычного вопроса — на кону 400 HP: Босс теряет 400 при верном, игрок сам получает 400 при неверном. Таймера нет.
  • ☠ Вопрос-проклятие (один раз за игру): верно — жертва (Босс или цель) восстанавливает +100; неверно — проклятие обрушивается сразу на ВСЕХ живых: −100 каждому.
  • 👹 Ярость Босса: с шансом 5% за каждый неправильный ответ Босс удваивает урон ошибшемуся (слышен рёв, всплывает «БОСС РАЗЪЯРЁН»).
  • 🎰 Казино (один раз за игру, только против Босса): вместо вопроса — колесо фортуны: исцеление, урон, пропуск хода, удар по Боссу или по случайному сопернику…
  • ⚡ Серия: пять верных ответов подряд — с шансом 5% Босс вместе с пятым ударом получает ещё +300 урона. Считаются только обычные вопросы.
  • 🔥 Конец II круга: если Босс ещё цел, он обрушивает удар по всем живым: −50 каждому (пулу каждой команды −100).
  • 👑 Конец III круга: зачистка — Босс забирает 2–4 самых слабых игроков (при уже погибших — 1–2 самых низких по HP; в командах — одну команду).
  • 💎 Способности (только в обычном и командном режимах, одна каждого типа за игру): 🔀 Замена — заменить вопрос на другой; ⚡ Азарт — урон ×2, но при ошибке сам получаешь 200; 🎴 Передача — отдать вопрос случайному сопернику и пропустить ход (только против Босса). Работают до нажатия «Показать ответы» и не работают на мега/проклятии.

🛡 Акт II. Мордобой

Дуэли идут в два шага, вопрос задаётся обоим участникам:

  • Атакующий (красная рамка) отвечает первым.
  • Если он верен — защитнику задаётся новый вопрос: защитник ответил верно → получает всего 50 урона; ошибся → полный урон по сложности.
  • Если атакующий промахнулся — урон пока не наносится, вопрос переходит защитнику (тот же вопрос): защитник верен → атакующий получает урон + 50; оба промахнулись → оба получают урон по вопросу.
  • Урон в Мордобое по сложности вопроса: 100 / 150 / 200.

Игра заканчивается, когда остаётся 3 живых: места по нанесённому урону, призы 5 / 3 / 2 балла. Если Босс уничтожил всех — на итогах красное «ПОРАЖЕНИЕ», баллов не получает никто. Если вопросы закончились раньше — итоги по урону и запасу HP.

🗺 Три режима

  • 🗡 Классика (одиночная) — 8–12 игроков, каждый сам за себя: 500/400/300 HP по числу участников, Босс — 1500 HP.
  • ⚡ Быстрый и мёртвый (быстрая) — короткий бой без сюрпризов: у всех по 250 HP, у Босса 750 HP. Никаких способностей, казино, мегавопросов и проклятий; Босс не бьёт по кругам и не устраивает зачистку. Мордобой — обычный.
  • 🛡 Война гильдий (командная) — 4–6 гильдий по 2 игрока: общий запас HP (вдвое больше), весь урон ×2 (кроме мегавопроса и проклятия), 20 секунд на ответ, баллы — гильдии. Очки говорят по очереди.
